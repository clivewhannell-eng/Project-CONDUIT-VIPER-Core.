
# Project CONDUIT & The VIPER Ocular System
### An End-to-End Computational Simulation of a Closed-Loop Brain-Computer Interface and Kinetic Actuation Chassis

## Project Abstract
Project **CONDUIT** (*Cerebrospinal Optoelectronic Neural Decoding and Ultra-fast Intent Transmission*) is a theoretical framework designed to intercept continuous biological motor commands at the medulla oblongata via a flexible graphene-polyimide Bio-FET mesh. The system digitizes, serializes, and routes these signals down an intrathecal fiber-optic conduit at optoelectronic speeds to bypass biological nerve latency. 

Simultaneously, the **VIPER** Ocular System (*Visual Intelligent Processing and Edge-computed Retinal prosthesis*) integrates a 500 Hz liquid-lens curved CMOS sensor array to feed high-frequency visual telemetry and a heads-up display directly into the central Spiking Neural Network (SNN).

## Software Architecture Framework (v2.0)
This repository contains a functional, object-oriented Python architecture that simulates the complete integrated loop under real-world physical and chemical constraints:
* **Real Data Ingestion Engine:** Simulates structured spatial-temporal matrix rows matching clinical human EEG/ECoG data formats.
* **Neuromorphic SNN Layer:** Implements a mathematically accurate Leaky Integrate-and-Fire (LIF) neural simulation to handle real-time intent classification under 1 microsecond.
* **Thermodynamic Dissipation Model:** Calculates kinetic strain loads (MPa) and real-time thermal friction heat generation of electroactive polymer (EAP) muscle structures against homeostatic biological human limits.
* **Pharmacokinetic Pump Simulator:** Monitors synthetic catecholamine agonist accumulation metrics and tracks neural excitotoxicity thresholds.

## Research & Academic Roadmap
This software acts as the baseline Phase 1 conceptual validation model. Future development milestones are mapped to a structured academic path focusing on undergraduate cellular/tissue engineering, cleanroom nanofabrication of graphene interfaces, and clinical neurosurgical integration partnerships.
